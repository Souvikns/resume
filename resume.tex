\section{Experience}
\role{Software Engineer II}{XANE.AI}{Gurugram, India}{Jul 2025 -- Present}
\begin{itemize}
  \item Built the Mastra agent behind Maruti Suzuki's AI assistant, which handles 100,000+ queries a day from 4.37M+ users across 34 vehicle models. It began as a RAG system over vehicle manuals and now also checks insurance policy status, handles renewals and quotes, and finds and books workshops.
  \item For retrieval, manuals go through MinerU OCR instead of manual data entry and are then chunked, embedded and searched in Qdrant with hybrid search and reranking.
  \item Built a separate deepagents system that sorts raw OCR output into CRM records.
  \item Added RAGAS evals on a golden set to CI (GitHub Actions) to flag quality regressions and set up self-hosted Langfuse for tracing. Answer relevance rose from 64\% to 89\%.
  \item Routed customer photos of car parts to a vision model whose output drives retrieval, and attached provenance metadata to every chunk so answers cite their sources.
  \item Deployed it on AWS, with Bedrock for the assistant's LLM and the part-identification vision model, EC2 for the backend, and S3 and RDS for vehicle manuals and metadata.
\end{itemize}
